# Оргструктура YBC

Інтерактивна схема-дерево оргструктури Young Business Club (один файл, без збірки).

- Сайт: `public/index.html` (публікується через GitHub Pages)
- Дані (посади, люди, філії) лежать на початку `<script>` у цьому ж файлі.
- Публікація: кожен push у `main` оновлює сайт автоматично.
